**Chapter 28 멀티미디어 연습 문제 풀이(답)**

1. \_\_\_\_\_\_\_ 압축에서 데이터의 무결성은 압축과 해제 알고리즘은 정확히 역의 관계이기 때문에 \_\_\_\_\_\_\_ .

-> a. 무손실, 보존한다.

2. 다음 압축 방법 중 무손실 압축이 아닌 것은?

-> d. 예측 부호화

3. Lempel Ziv Welch(LZW) 방법은 \_\_\_\_\_\_\_ 의 예제이다.

-> b. 사전 부호화

4. \_\_\_\_\_\_\_ 은 좀 더 자주 발생하는 심벌에 더 짧은 코드를 할당하고 적게 발생하는 심벌에 짧은 코드를 할당한다.

-> d. 허프만 부호화

5. 산술 부호화에서 전체 메시지는 \_\_\_\_\_\_\_ 구간의 실제 숫자로 매핑된다.

-> c. [0, 1)

6. 다음 압축 방법 중 예측 부호화로 간주되는 것은 무엇인가?

-> d. A, B, C 모두 (a. DM, b. DPCM, c. LPC)

7. 각 샘플을 분히라는 양자화 대신에 \_\_\_\_\_\_\_ 에서 차이점은 양자화되어 있다.

-> a. 예측 부호화

8. 적응형 델타변조는 델타 변호에서 \_\_\_\_\_\_\_ 의 문제를 풀기 위해서 사용된다.

-> c. 과부하 왜곡 혹은 입상 잡음

9. \_\_\_\_\_\_\_ 은 높은 수준의 압축을 달성하고, 일반적으로 연설의 압축을 위해서 군대에서 사용한다. 합성된 연설은 스피커를 식별할 수 있는 품질과 자연스러움이 이해하기 부족하다. (해석 이상)

-> a. LCP

10. \_\_\_\_\_\_\_ 부호화는 사람이 어떻게 소리를 감지하는지를 연구하는 음향 심리학을 기반으로 한다.

-> b. 지각

11. 멀티미디어에서 사용되는 변환 부호화의 단계 중 손실 방법은 무엇인가?

-> b. 양자화 단계

12. 사각 행렬로 표현되는 DCT 계수값은 역과 전치가 같은 \_\_\_\_\_\_\_ 행렬이다.

-> c. 직교

13. \_\_\_\_\_\_\_ 은 이미지 압축을 위해서 사용된다.

-> b. JPEG

14. JPEG 압축 과정의 첫 번째 단계는 \_\_\_\_\_\_\_ 이다.

-> a. DCT 변환

15. JPEG 압축 과정의 두 번째 단계는 \_\_\_\_\_\_\_ 이다.

-> b. 양자화

16. JPEG 의 세 번째 단계는 \_\_\_\_\_\_\_ 이다.

-> c. 무손실 압축 부호화

17. \_\_\_\_\_\_\_ 은 비디오 압축에 사용되어진다.

-> a. MPEG

18. MPEG 방법에서 각 프레임의 \_\_\_\_\_\_\_ 압축은 JPEG과 함께 수행된다.

-> b. 공간적, 일시적

19. \_\_\_\_\_\_\_ AV는 압축된 AV파일을 위해 주문형 요청을 나타낸다.

-> b. 저장된 스트리밍

20. \_\_\_\_\_\_\_ AV는 인터넷을 통해서 라디오와 TV 프로그램의 방송을 나타낸다.

-> a. 라이브 스트리밍

21. \_\_\_\_\_\_\_ AV는 양방향 AV 응용을 위해 인터넷을 사용하는 것을 나타낸다.

-> c. 양방향

22. \_\_\_\_\_\_\_ 버퍼는 실시간 트래픽을 위해 요구된다.

-> a. 재생

23. 패킷의 시간 관계성과 순서를 설립하기 위해서 실시간 트래픽은 각 패킷에 \_\_\_\_\_\_\_ 필요하다.

-> c. 타임스탬프와 순서 번호 둘 다

24. \_\_\_\_\_\_\_ 은 페이로드의 부호화를 수신 네트워크의 대역폭을 맞추기 위해 낮은 품질로 변화시키는 것을 의미한다.

-> a. 변형 (변환)

25. \_\_\_\_\_\_\_ 은 트래픽의 여러 스트림을 하나의 스트림으로 결합하는 것을 의미한다.

-> b. 혼합

26. 손실 및 손상된 패킷을 만들어 내기 위해, 일반적으로 실시간 트래픽은 \_\_\_\_\_\_\_ .

-> b. 전방향 오류 수정(FEC)방법을 사용한다.

27. 실시간 비디오 성능은 10분 정도 소요된다. 시스템에 지터가 있는 경우, 뷰어는 성능을 보이기 위해서 \_\_\_\_\_\_\_ 소비한다.

-> b. 10분보다 더 많이

28. \_\_\_\_\_\_\_ 은 패킷이 첫 번째 혹은 전의 패킷과 관련되어 생성되는 시간을 보여준다.

-> a. 타임스탬프

29. \_\_\_\_\_\_\_ 는 실시간 전송의 패킷 번호를 사용한다.

-> c. 순서 번호

30. \_\_\_\_\_\_\_ 는 다른 소스들로 부터 단일 합성 신호를 생성하기 위해서 신호를 추가한다.

-> c. 혼합기

31. \_\_\_\_\_\_\_ 는 높은 대역폭 비디오의 포맷을 낮은 품질의 협대역 신호로 변화시킨다.

-> c. 번역기 (변환기)

32. \_\_\_\_\_\_\_ 는 멀티미디어 세션을 달성하고, 관리하고 종료하는 응용층 프로토콜이다.

-> a. SIP

33. \_\_\_\_\_\_\_ 는 공중전화 네트워크의 전화가 인터넷에 연결된 컴퓨터와 대화하기 위해 ITU로 설계된 표준이다.

-> b. H.323

34. \_\_\_\_\_\_\_ 는 패킷의 재전송을 허락하지 않기 때문에 양방향 멀티미디어 트래픽에 적당하지 않다.

( \_\_\_\_\_\_\_ 는 대화형 멀티미디어 트래픽에 적합하지 않다. 왜냐하면 대화형 멀티미디어는 패킷의 재전송을 허용하지 않기 때문이다. )

-> a. TCP

35. \_\_\_\_\_\_\_ 는 인터넷상의 실시간 트래픽을 다루기 위해서 설계된 프로토콜이다.

-> c. RTP

36. \_\_\_\_\_\_\_ 는 RTP에 관련하여 흐름과 데이터의 품질을 제어하기 위한 프로토콜이다.

-> b. RTCP

37. RTP 패킷은 \_\_\_\_\_\_\_ 에서 캡슐화된다.

-> a. UDP 사용자 데이터그램
