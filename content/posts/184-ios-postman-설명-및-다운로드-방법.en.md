Postman이란 Rest API 통신 서버를 본격적으로 구축하기 전 테스트 할 수 있도록 도와주는 GUI 툴이라고 생각하면 쉽게 이해될 것 같습니다. 윈도우, 리눅스에서도 사용 가능하고 WEB 버전도 있지만 이 포스팅에서는 macOS를 기준으로 진행하겠습니다.

사용자가 개인이고 기본적인 기능만 사용한다고 하면 무료로 사용할 수 있습니다. 비용에 관한 자세한 부분은 홈페이지에 기재되어 있습니다.

![](https://img.sobamemil.com/posts/184/img_1.png)

Postman 다운로드 링크 :

<https://www.postman.com/downloads/>

[Download Postman | Try Postman for Free

Try Postman for free! Join 13 million developers who rely on Postman, the collaboration platform for API development. Create better APIs—faster.

www.postman.com](https://www.postman.com/downloads/)

위의 링크를 들어가면 다음과 같은 화면이 나오는데 Download the App 버튼을 클릭하여 Postman 파일을 다운받습니다.

![](https://img.sobamemil.com/posts/184/img_2.png)

아래와 같이 Postman 압축 파일이 받아졌습니다.

![](https://img.sobamemil.com/posts/184/img_3.png)

압축을 풀어주면 본격적인 파일이 나옵니다. 그럼 파일을 실행시켜줍니다.

![](https://img.sobamemil.com/posts/184/img_4.png)

아래와 같은 애플리케이션이 실행되고, 처음 사용하는 경우에는 Create Free Account 버튼을 눌러 회원가입을 해줍니다.

![](https://img.sobamemil.com/posts/184/img_5.png)

위에서부터 순서대로 이메일, 이름(아이디), 비밀번호를 입력해줍니다.

계정 등록 이후 직업군을 물어보고 팀 이름을 입력하라고 나오는데 건너뛸 수 있습니다.

![](https://img.sobamemil.com/posts/184/img_6.png)

계정 등록까지 완료했으면 아래와 같은 화면이 반겨줍니다. 다운로드 및 설치가 완료되었습니다.

![](https://img.sobamemil.com/posts/184/img_7.png)
