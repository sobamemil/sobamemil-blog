**Chapter 14 다른 유선 네트워크들 Practice ExercisesSolution(답)**

1. ADSL에서 대역폭의 많은 부분은 \_\_\_\_\_\_\_ 을 전송하는 것이다.

-> c. 하향 데이터

2. 케이블 TV 사무실의 다른 이름은 \_\_\_\_\_\_\_ 이다.

-> d. 꼭지 끝(head end)

3. 전통적인 케이블 TV네트워크에서 신호는 \_\_\_\_\_\_\_ 로 전송된다.

-> b. 하향

4. 전화 시스템을 의미하는 original 전화 네트워크는 \_\_\_\_\_\_\_ 시스템이다.

-> b. 아날로그

5. 전통적인 케이블 TV 시스템은 종단-대-종단을 연결하기 위해 \_\_\_\_\_\_\_ 케이블을 사용한다.

-> b. 동축

6. 2세대 케이블 네트워크는 \_\_\_\_\_\_\_ 네트워크라 불린다.

-> a. HFC

7. HFC 네트워크는 \_\_\_\_\_\_\_ 케이블을 사용한다.

-> d. 광섬유와 동축 케이블의 조합

8. 데이터 전송에서 케이블 네트워크를 사용하기 위해, \_\_\_\_\_\_\_ 와 \_\_\_\_\_\_\_ 의 중요 장치가 필요하다.

-> c. CM; CMTS

9. \_\_\_\_\_\_\_ 신호는 전기 신호 세기 STS-n의 광학 신호를 나타낸다.

-> a. OC-n

10. SONET은 \_\_\_\_\_\_\_ TDM 다중화를 사용한다.

-> b. 동기

11. SONET 시스템은 \_\_\_\_\_\_\_ 을 사용한다.

-> d. 모든 선택지가 Answers & Solutions이다. (a. STS 다중화기, b. 재생기, c. 추가/삭제 다중화기)

12. SONET은 초당 \_\_\_\_\_\_\_ 프레임을 전송한다.

-> d. 8000

13. SONET에서 \_\_\_\_\_\_\_ 는 신호의 삽입과 추가를 가능하게 한다.

-> b. ADMs

14. SONET에서 각 바이트에 대해 비트는 \_\_\_\_\_\_\_ 전송된다.

-> b. 최상위에서 최하위까지

15. \_\_\_\_\_\_\_ 는 포럼에 의해 디자인되고 ITU-T에 의해 채택된 셀 중계 프로토콜이다.

-> c. ATM

16. ATM 표준은 \_\_\_\_\_\_\_ 계층을 정의한다.

-> b. 3

17. ATM 데이터 유닛은 \_\_\_\_\_\_\_ 바이트로 압축된 셀이다.

-> d. 53

18. ATM에서 \_\_\_\_\_\_\_ 는 사용자와 ATM 교환기 사이의 인터페이스이다.

-> a. UNI

19. ATM에서 \_\_\_\_\_\_\_ 는 두 ATM 교환기 사이의 인터페이스이다.

-> b. NNI

20. ATM에서 \_\_\_\_\_\_\_ 계층은 상위 계층 서비스로의 전송을 허용하고, 셀에 매핑한다.

-> c. AAL

21. ATM에서 \_\_\_\_\_\_\_ 계층은 라우팅, 트래픽 관리, 교환과 다중화 서비스를 제공한다.

-> b. ATM

22. SONET에서 \_\_\_\_\_\_\_ 는 중계기이다.

-> a. 재생기
