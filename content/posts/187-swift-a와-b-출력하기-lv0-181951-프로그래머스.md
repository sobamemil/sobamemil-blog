**문제:**

정수 a와 b가 주어집니다. 각 수를 입력받아 입출력 예와 같은 형식으로 출력하는 코드를 작성해 보세요.

programmers.co.kr](https://school.programmers.co.kr/learn/courses/30/lessons/181951)

<b>제한사항:</b>

* -100,000 ≤ a, b ≤ 100,000

<b>풀이:</b>

```cpp
let n = readLine()!.components(separatedBy: [" "])
let (a, b) = (n[0], n[1])

print("a = \(a)\nb = \(b)")

// 또는 
// print("a =", a)
// print("b =", b)
```

두 가지의 정수를 공백 기준으로 나눈 후, 형식에 맞게 출력 해주면 되는 문제입니다.

출력은 아주 다양한 방법으로 할 수 있습니다 ~
