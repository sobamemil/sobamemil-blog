**Chapter 6 아날로그대역폭 활용: 다중화와 스펙트럼 확장 전송 연습 문제 풀이(답)**

1. 아날로그 신호를 전송하는 다중화 기술은?

-> a. FDM

2. 디지털 신호를 전송하는 다중화 기술은?

-> b. TDM

3. 다음 중 각 신호를 서로 다른 반송파로 전달하는 다중화 기술은?

-> a. FDM

4. 광선 빔으로 구성된 신호를 사용하는 다중화 기술은?

-> c. WDM

5. \_\_\_\_\_\_\_ 은 단일 회선을 사용하여 여러 신호를 동시에 전송하는 것을 허용하는 기술들이다.

-> b. 다중화

6. \_\_\_\_\_\_\_ 은 광섬유의 높은 대역폭을 이용하기 위해 설계되었다.

-> c. WDM

7. \_\_\_\_\_\_\_ 은 광신호를 결합하는 아날로그 다중화 기술이다.

-> c. WDM

8. \_\_\_\_\_\_\_ 은 링크의 높은 대역폭을 위해 여러 연결을 허용하는 디지털 처리 절차이다.

-> b. TDM

9. \_\_\_\_\_\_\_ 을 동기식 및 통계적 기법으로 나눌 수 있다.

-> b. TDM

10. \_\_\_\_\_\_\_ TDM에서는 각 입력 연결은 데이터를 전송하지 않는 경우에도 출력을 할당받고 있다.

-> a. 동기식

11. \_\_\_\_\_\_\_ TDM에서는 대역폭 효율을 높이기 위해 슬롯이 동적으로 할당된다.

-> b. 통계적

12. \_\_\_\_\_\_\_ 기술은 원시 신호에 의해 변조된 M개의 서로 다른 반송 주파수를 사용한다. 한 순간에는 신호는 어떤 반송파를 변조하고 다음 순간에는 다른 반송파를 변조한다.

-> c. FHSS

13. \_\_\_\_\_\_\_ 기술은 확장 코드를 이용하여 각 데이터 비트를 n개의 비트로 대체하여 신호의 대역폭을 확장한다.

-> b. DSSS

14. 그룹, 슈퍼그룹, 주 그룹, 점보 그룹은 \_\_\_\_\_\_\_ 에서 사용하는 용어이다.

-> a. FDM

15. 다중레벨 다중화는 \_\_\_\_\_\_\_ 에서 사용하는 전략이다.

-> d. TDM

16. 다중 슬록 할당은 \_\_\_\_\_\_\_ 에서 사용하는 기술이다.

-> d. TDM

17. 펄스 채워넣기는 \_\_\_\_\_\_\_ 에서 사용하는 전략이다.

-> d. TDM

18. 프레임 동기화는 \_\_\_\_\_\_\_ 에서 사용하는 전략이다.

-> d. TDM

19. T-1 회선은 \_\_\_\_\_\_\_ 프레임을 사용한다.

-> b. 8000

20. \_\_\_\_\_\_\_ TDM에서는 주소지정 메커니즘이 필요하다.

-> b. 통계적
