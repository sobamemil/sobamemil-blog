**Chapter 11 데이터링크 제어(DLC) 연습 문제 풀이(답)**

1. HDLC는 \_\_\_\_\_\_\_ 의 줄임말이다.

-> c. High-Level Data Link Control

2. HDLC 프로토콜에서 가장 짧은 프레임은 항상 \_\_\_\_\_\_\_ 프레임이다.

-> c. 감시

3. HDLC에서 프레임의 주소 필드는 \_\_\_\_\_\_\_ 지국의 주소를 포함한다.

-> b. 두 번째

4. HDLC \_\_\_\_\_\_\_ 필드는 프레임의 처음과 끝을 정의한다.

-> b. 플래그

5. 다음 중 모든 HDLC 제어 필드에 있는 것은 무엇인가?

-> d. P/F 비트

6. PPP 천이단계 다이어그램에 따르면, 옵션들은 \_\_\_\_\_\_\_ 상태에서 협상된다.

-> c. 설정

7. PPP 천이단계 다이어그램에 따르면, 사용자 식별자 확인은 \_\_\_\_\_\_\_ 상태에서 발생한다.

-> d. 인증

8. PPP 프레임에서 \_\_\_\_\_\_\_ 필드는 데이터 필드의 콘텐츠를 정의한다.

-> d. 프로토콜

9. PPP 프레임에서 \_\_\_\_\_\_\_ 필드는 HDLC에서 U-프레임의 것과 유사하다.

-> d. 제어

10. PPP 프레임에서 \_\_\_\_\_\_\_ 필드는 HLC의 브로드캐스트 주소를 나타내기 위해 11111111의 값을 가진다.

-> b. 주소

11. PPP에서 LCP 패킷의 목적은 무엇인가?

-> d. 모든 선택지가 정답이다.

12. PPP 프레임에서 \_\_\_\_\_\_\_ 필드는 오류 제어를 담당한다.

-> a. FCS

13. CHAP 인증에서 사용자는 시스템으로 전송하는 결과를 만들기 위해, 시스템의 \_\_\_\_\_\_\_ 와 그것의 고유한 \_\_\_\_\_\_\_ 을 가진다.

-> c. 챌린지 값, 패스워드

14. 바이트 채우기에서, 때때로 페이로드에 \_\_\_\_\_\_\_ 를 추가할 필요가 있다.

-> b. ESC 바이트

15. 비트 스터핑에서 때때로 페이로드에 추가적인 \_\_\_\_\_\_\_ 비트를 추가할 필요가 있다.

-> a. 0의

16. HDLC는 \_\_\_\_\_\_\_ 지향 프로토콜이다.

-> b. 비트

17. PPP는 \_\_\_\_\_\_\_ 지향 프로토콜이다.

-> a. 바이트

18. PPP에서 주소 필드는 패킷의 \_\_\_\_\_\_\_ 를 정의한다.

-> d. 정답 없음

19. PPP에서 \_\_\_\_\_\_\_ 필드는 프레임에 캡슐화된 페이로드의 종류를 정의한다.

-> c. 프로토콜

20. PPP에서 CHAP 프로토콜은 통신에서 패리티를 인증하기 위해 \_\_\_\_\_\_\_ 단계를 사용한다.

-> c. 3개의
