**Chapter 15 무선 LAN 연습 문제 풀이(답)**

1. 다음 유선과 무선 LAN의 설명 중 옳은 것은?

-> a. 둘 다 TCP/IP 프로토콜 슈트의 하위 두 계층에서 동작한다. (물리층, 데이터링크층)

2. IEEE는 \_\_\_\_\_\_\_ 으로 불리는 물리층과 데이터링크층을 포함하는 무선 LAN의 세부사항을 정의하였다.

-> c. IEEE 802.11

3. CSMA/CD 알고리즘은 무선 LAN에서 사용되지 않는데 그 이유는?

-> d. 모두 정답 (a. 무선 호스트가 이중 모드(duplex mode)로 작동하기 위한 충분한 전력을 가지고 있지 않아서, b. 숨겨진 지국 문제 때문에, c. 신호 감쇠로 한 지국이 반대편에서 발생한 충돌을 감지할 수 없어서)

4. IEEE 802.11에서 \_\_\_\_\_\_\_ 은 정지한 혹은 이동 무선국과 선택적으로 접근점(AP)으로 알려진 중앙 기지국을 포함한다.

-> b. BSS

5. IEEE 802.11 에서 AP를 제외한 BSS를 \_\_\_\_\_\_\_ (이)라고 한다.

-> a. 애드 혹 구조 (an ad hoc architecture)

6. IEEE 802.11에서 AP를 포함한 BSS를 종종 \_\_\_\_\_\_\_ 으로 나타낸다.

-> b. 기반 네트워크 (an infrastructure network)

7. IEEE 802.11에서 2개의 다른 BSS의 두 지국 간의 통신은 종종 2개의 \_\_\_\_\_\_\_ 을 통해 이루어진다.

-> c. APs

8. IEEE 802.11에서 \_\_\_\_\_\_\_ 이동이 가능한 지국은 정적(움직이지 않음)이거나 BSS 내에서만 이동한다.

-> a. 무전이

9. IEEE 802.11에서 \_\_\_\_\_\_\_ 이동이 가능한 지국은 하나의 BSS에서 다른 곳으로 이동이 가능하지만 이동은 하나의 ESS 내로만 제한된다.

-> b. BSS 전이

10. IEEE 802.11에서 \_\_\_\_\_\_\_ 이동이 가능한 지국은 ESS간의 이동이 가능하다.

-> c. ESS 전이

11. IEEE 802.11에서 분산 조정 함수(DCF)는 접속 기법으로 \_\_\_\_\_\_\_ 을 사용한다.

-> a. CSMA/CA

12. IEEE 802.11에서 한 BSS의 지국에서 다른 BSS의 지국으로 프레임이 전달될 때 주소 플래그는 \_\_\_\_\_\_\_ 이다.

-> 00

13. IEEE 802.11에서 AP에서 지국으로 향하는 프레임의 주소 플래그는 \_\_\_\_\_\_\_ 이다.

-> b. 01

14. IEEE 802.11에서 지국에서 AP로 향하는 프레임의 주소 플래그는 \_\_\_\_\_\_\_ 이다.

-> c. 10

15. IEEE 802.11에서 프레임이 무선 분산 시스템의 한 AP에서 다른 AP로 이동할 때 주소 플래그는 \_\_\_\_\_\_\_ 이다.

-> d. 11

16. IEEE 802.11에서 PCF 부계층에서 사용하는 접속 기법은 \_\_\_\_\_\_\_ 이다.

-> c. 폴링

17. IEEE 802.11에서 \_\_\_\_\_\_\_ 은 충돌 회피에 사용되는 시간이다.

-> a. NAV

18. IEEE 802.11에서 주소 기법은 최대 \_\_\_\_\_\_\_ 개의 주소를 포함할 수 있다.

-> a. 4

19. 본래의 IEEE 802.11은 \_\_\_\_\_\_\_ (을)를 사용한다.

-> d. FHSS나 DSSS

20. IEEE 802.11a는 \_\_\_\_\_\_\_ (을)를 사용한다.

-> c. OFDM

21. IEEE 802.11b는 \_\_\_\_\_\_\_ (을)를 사용한다.

-> b. DSSS

22. IEEE 802.11g는 \_\_\_\_\_\_\_ (을)를 사용한다.

-> c. OFDM

23. IEEE 802.11 FSSS는 \_\_\_\_\_\_\_ 변조를 사용한다.

-> b. FSK

24. IEEE 802.11나 IEEE 802.11b DSSS는 \_\_\_\_\_\_\_ 변조를 사용한다.

-> c. PSK

25. IEEE 802.11a, IEEE 802.11g, 혹은 IEEE 802.11n OFDM은 \_\_\_\_\_\_\_ 변조를 사용한다.

-> d. 정답 없음 (a. ASK, b. FSK, c. PSK)

26. 블루투스는 작은 지역에서 기기(가드겟이라 불리는)를 연결하기 위한 \_\_\_\_\_\_\_ 기술이다.

-> d. 정답 없음 (정답 : PAN) (a. 유선 LAN, b. 무선 LAN, c. VLAN) 

27. 블루투스에서 다중 \_\_\_\_\_\_\_ 은 \_\_\_\_\_\_\_ 으로 불리는 네트워크를 형성한다.

-> b. 피코넷, 스캐터넷

28. 블루투스 네트워크는 **\_\_\_\_\_\_\_**개의 주국과 최대 \_\_\_\_\_\_\_ 개의 종국으로 구성된다.

-> d. 1, 7

29. 블루투스에서 현재 데이터율은 \_\_\_\_\_\_\_ Mbps이다.

-> d. 정답 없음 (a. 2, b. 5, c. 11)

30. 블루투스의 접속 기법은 \_\_\_\_\_\_\_ 이다.

-> b. TDD-TDMA

31. 블루투스에서 \_\_\_\_\_\_\_ 링크는 지연을 줄이는 것보다 데이터의 무결성이 더 중요할 때 사용된다.

-> b. ACL

32. 블루투스는 다른 장치나 다른 네트워크로부터 간섭을 회피하기 위해 물리층에서 \_\_\_\_\_\_\_ 을 사용한다.

-> b. FHSS
