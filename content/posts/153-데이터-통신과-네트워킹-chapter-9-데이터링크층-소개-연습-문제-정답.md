**Chapter 9 데이터링크층 소개 전송 연습 문제 풀이(답)**

1. 데이터링크층에서 통신은 \_\_\_\_\_\_\_ 이다.

-> b. 노드-대-노드

2. \_\_\_\_\_\_\_ 는 지역주소이다. 그 범위는 지역 네트워크를 넘어서지 않는다.

-> a. 링크계층 주소

3. 만약 송신자가 호스트이고, 같은 네트워크에 있는 다른 호스트로 패킷을 전송하고자 하면, 물리 주소와 매핑되는 논리적 주소는 \_\_\_\_\_\_\_ 이다.

-> a. 데이터그램 헤더 안에 있는 목적지 IP 주소

4. 만약 송신자가 호스트이고 다른 네트워크에 있는 다른 호스트로 패킷을 전송하고자 할 때, 물리 주소와 매핑되는 논리적 주소는 \_\_\_\_\_\_\_ 이다.

-> b. 라우팅 테이블에서 찾을 수 있는 라우터의 IP 주소

5. 발신자는 다른 네트워크에 있는 호스트로 향하는 데이터그램을 수신한 라우터이다. 물리 주소와 매핑되는 논리적 주소는 \_\_\_\_\_\_\_ 이다.

-> b. 라우팅 테이블에서 찾을 수 있는 라우터의 IP 주소

6. 발신자는 동일한 네트워크에 있는 호스트로 향하는 데이터그램을 수신한 라우터이다. 물리 주소와 매핑되는 논리적 주소는 \_\_\_\_\_\_\_ 이다.

-> a. 데이터그램 헤더 안에 있는 목적지 IP 주소

7. ARP 응답은 일반적으로 \_\_\_\_\_\_\_ 이다.

-> c. 유니캐스트

8. ARP 요청은 일반적으로 \_\_\_\_\_\_\_ 이다.

-> a. 브로드캐스트

9. 데이터링크층에서 패킷은 일반적으로 \_\_\_\_\_\_\_ 라 부른다.

-> c. 프레임

10. \_\_\_\_\_\_\_ 링크에서 링크는 장치들 사이에서 공유되지 않는다.

-> b. 점-대-점

11. \_\_\_\_\_\_\_ 링크에서 링크는 장치 사이에서 공유된다.

-> a. 브로드캐스트

12. 브로드캐스트 링크의 데이터링크층은 \_\_\_\_\_\_\_ 의 부계층을 갖는다.

-> b. 2개

13. 점-대-점 링크의 데이터링크층은 \_\_\_\_\_\_\_ 의 부계층을 갖는다.

-> a. 1개

14. 미디어 접속 제어는 오직 \_\_\_\_\_\_\_ 링크에서 나타난다.

-> d. 정답 없음
