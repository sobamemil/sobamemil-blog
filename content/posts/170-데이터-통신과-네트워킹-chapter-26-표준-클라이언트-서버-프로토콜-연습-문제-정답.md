**Chapter 26 표준 클라이언트-서버 프로토콜 연습 문제 풀이(답)**

1. HTTP는 \_\_\_\_\_\_\_ 의 서비스를 사용한다.

-> c. TCP

2. HTTP에서 요청 메시지의 첫 번째 라인은 \_\_\_\_\_\_\_ 라인이며, 응답 메시지의 첫 번째 라인은 \_\_\_\_\_\_\_ 라인이다.

-> d. 정답이 없음 (요청; 상태) (a. 요청; 응답, b. 상태; 응답, c. 상태; 상태)

3. \_\_\_\_\_\_\_ 접속에서 하나의 TCP 연결은 각각 요청/응답으로 구성되어 있다.

-> b. 비영구적

4. \_\_\_\_\_\_\_ 연결에서 서버는 응답을 전송한 후 더 많은 요청을 위해 연결을 열어놓은 채 접속을 남겨둔다.

-> a. 영구적

5. HTTP에서 \_\_\_\_\_\_\_ 서버는 최근 요청에 대한 응답 사본을 가지고 있는 컴퓨터이다.

-> b. 프록시(proxy)

6. 메시지를 요청하는 HTTP는 항상 \_\_\_\_\_\_\_ 를 가진다.

-> b. 요청 라인과 헤더 라인

7. 아래 중 HTTP의 요청 라인과 상태 라인 양쪽에 존재하는 것은 무엇인가?

-> a. 버전 번호(version number)

8. FTP는 \_\_\_\_\_\_\_ 의 서비스를 사용한다.

-> c. TCP

9. FTP는 \_\_\_\_\_\_\_ 의 잘 알려진 포트를 사용한다.

-> b. 2개

10. FTP 세션이 유지되는 동안 제어 연결은 \_\_\_\_\_\_\_ 열려진다.

-> a. 한 번 

11. FTP 세션이 유지되는 동안 데이터 연결은 \_\_\_\_\_\_\_ 열려진다.

-> c. 필요한 만큼 많이

12. FTP에서 파일은 레코드, 페이지 또는 바이트의 흐름으로 조직될 수 있다.

-> b. 데이터 구조

13. FTP에서 스트림, 블록, 압축된 세 가지 형식의 \_\_\_\_\_\_\_ 이 있다.

-> c. 전송 모드

14. FTP, ASCII, EBCDIC와 이미지는 \_\_\_\_\_\_\_ 라 불리는 속성을 정의한다.

-> a. 파일 형식

15. FTP에서 \_\_\_\_\_\_\_ 할 때, 파일은 클라이언트로부터 서버로 복사된다.

-> b. 파일을 저장

16. 일반적인 시나리오에서 전자우편 시스템은 \_\_\_\_\_\_\_ 를 필요로 한다.

-> c. 2개의 UA, 2짝의 MTA, 1짝의 MAA

17. \_\_\_\_\_\_\_ 는 사용자에게 메시지를 쉽게 송신하거나 수신하는 과정을 만드는 서비스를 제공한다.

-> c. UA

18. 이메일 메시지는 \_\_\_\_\_\_\_ 와 \_\_\_\_\_\_\_ 로 구성된다.

-> d. 정답 없음 (봉투; 메시지) (a. 헤더; 봉투(header; envelop), b. 헤더; 바디(header; body), c. 봉투; 바디(envelop; body))

19. 인터넷에서 이메일 주소는 두 부분, \_\_\_\_\_\_\_ 와 \_\_\_\_\_\_\_ 로 구성된다.

-> a. 로컬 부분; 도메인 부분(local part; domain name)

20. 이메일을 통해 전송된 ASCII가 아닌 데이터를 허용하는 보충 프로토콜은 \_\_\_\_\_\_\_ 이다.

-> c. MIME

21. 인터넷에서 MTA 클라이언트와 서버를 규정하는 정규 프로토콜은 \_\_\_\_\_\_\_ 이다.

-> a. SMTP

22. SMTP는 \_\_\_\_\_\_\_ 프로토콜이다.

-> b. push

23. 메시지 접근 프로토콜은 \_\_\_\_\_\_\_ 프로토콜이다.

-> a. pull

24. \_\_\_\_\_\_\_ 부호화 방법에서, 각 24비트들은 4개의 6비트 덩어리가 되고 결국 32비트로 전송된다.

-> c. base64

25. \_\_\_\_\_\_\_ 부호화 방법에서, non-ASCII 문자는 3개의 문자로 보내진다.

-> c. quoted-printable

26. TELNET은 \_\_\_\_\_\_\_ 를 위한 약어이다.

-> a. 터미널 네트워크

27. 사용자가 로컬 시분할 시스템에 로그인할 때를 \_\_\_\_\_\_\_ 로그인이라 부른다.

-> a. 로컬(local)

28. 사용자가 원격 기계에 있는 애플리케이션 프로그램이나 유틸리티에 접근을 원할 때, 사용자는 \_\_\_\_\_\_\_ 로그인을 수행한다.

-> b. 원격(remote)

29. 네트워크 가상 터미널 (NVT)는 \_\_\_\_\_\_\_ 를 위해 하나, \_\_\_\_\_\_\_ 를 위한 또 하나의 2개의 문자 집합을 사용한다.

-> c. 데이터; 제어(data; control)

30. 데이터를 위해 NVT는 최상위 비트가 \_\_\_\_\_\_\_ 로 설정된 US 아스키 문자를 사용한다.

-> b. 0

31. 제어를 위해 NVT는 최상위 비트가 \_\_\_\_\_\_\_ 로 설정된 US 아스키 문자를 사용한다.

-> a. 1

32. \_\_\_\_\_\_\_ 는 로컬 문자를 NVT 문자로 해석한다.

-> b. 텔넷 클라이언트(TELNET client)

33. \_\_\_\_\_\_\_ 는 원격 운영 시스템에 의해 받아들일 수 있는 형태로 NVT 문자를 해석한다.

-> c. 텔넷 서버(TELNET server)

34. SSH에 있는 \_\_\_\_\_\_\_ 구성요소는 기밀성, 무결성, 인증, 압축을 제공한다.

-> d. SSH-TRAN

35. 포트 포워딩은 \_\_\_\_\_\_\_ 이다.

-> c. 보안 서비스를 제공하지 않는 애플리케이션 프로그램을 위한 안전한 채널을 만드는 SSH에 의해 제공된 서비스

36. \_\_\_\_\_\_\_ 이름 공간에서, 이름은 구조 없는 문자의 순서이다.

-> b. 단층적(flat)

37. \_\_\_\_\_\_\_ 이름 공간에서, 각 이름은 여러 부분으로 구성되어 있다.

-> c. 계층적(hierarchical)

38. DNS에서 이름은 \_\_\_\_\_\_\_ 구조로 규정된다.

-> b. 반전된 트리(inverted-tree)

39. DNS 트리의 루트는 \_\_\_\_\_\_\_ 이다.

-> d. 빈 스트링(empty string)

40. 도메인 이름 공간에서 전체 도메인 이름은 \_\_\_\_\_\_\_ 에 의해 구분된 레이블의 순서이다.

-> c. 점(dot)

41. 도메인 이름 공간에서 레이블이 빈 문자로 종료되는 경우 \_\_\_\_\_\_\_ 라 한다.

-> d. 정답 없음 (FQDN) (a. PQDN, b. CQDN, c. SQDN)

42. 도메인 이름 공간에서 레이블이 빈 문자로 종료되지 않는 경우를 \_\_\_\_\_\_\_ 라 한다.

-> b. PQDN

43. 도메인 이름 공간에서 \_\_\_\_\_\_\_ 는 도메인 이름 공간의 하위 트리이다.

-> c. 도메인(domain)

44. 도메인 이름 공간에서 책임이 있거나 권한을 가진 서버를 \_\_\_\_\_\_\_ 라 부른다.

-> c. 영역(zone)

45. \_\_\_\_\_\_\_ 서버는 전체 트리를 구성하는 영역 시스템을 가진 컴퓨터이다.

-> c. 루트(root)

46. \_\_\_\_\_\_\_ 서버는 권한을 가진 영역에 대한 파일을 저장하는 컴퓨터이다.

-> a. 일차(primary)

47. \_\_\_\_\_\_\_ 서버는 다른 서버의 영역에 대한 정확한 정보를 전송하는 컴퓨터이다.

-> b. 이차(secondary)

48. 인터넷에서 국가 도메인 영역은 \_\_\_\_\_\_\_ 국가 약어를 사용한다.

-> a. 두 글자

49. \_\_\_\_\_\_\_ 해결에서 해결자는 마지막 응답을 제공하는 서버를 기대한다.

-> b. 재귀(recursive)

50. \_\_\_\_\_\_\_ 해결에서 서버는 질의를 해결할 수 있다고 생각하는 서버의 IP 주소를 반환한다.

-> a. 반복(iterative)

51. DNS는 \_\_\_\_\_\_\_ 의 서비스를 사용할 수 있다.

-> c. UDP 또는 TCP
