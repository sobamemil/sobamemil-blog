**Chapter 31 암호화와 네트워크 보안 연습 문제 풀이(답)**

1. 보안의 세 가지 목적은 \_\_\_\_\_\_\_ 이다.

-> c. 기밀성, 무결성, 가용성

2. 다음의 공격 중에서 무결성을 위협하는 것은?

-> a. 위장

3. 다음의 공격 중에서 가용성을 위협하는 것은?

-> c. 서비스 거부

4. \_\_\_\_\_\_\_ 는 연산을 통하여 메시지의 내용을 감추는 것을 의미한다.

-> b. 암호화

5. \_\_\_\_\_\_\_ 는 무언가로 메시지를 덮어서 감추는 것을 의미한다.

-> a. 스테가노그라피

6. \_\_\_\_\_\_\_ 암호화에서, 송신자와 수신자는 같은 키를 사용한다.

-> a. 대칭키

7. \_\_\_\_\_\_\_ 암호화에서, 양방향으로 같은 키를 사용한다.

-> a. 대칭키

8. \_\_\_\_\_\_\_ 암호는 종종 긴 메시지를 위해 사용된다.

-> a. 대칭키

9. \_\_\_\_\_\_\_ 암호는 종종 짧은 메시지를 위해 사용된다.

-> b. 비대칭키

10. \_\_\_\_\_\_\_ 는 송신자와 수신자가 기밀성을 기대한다는 것을 의미한다.

-> d. 정답 없음 (a. 부인방지, b. 무결성, c. 인증)

11. \_\_\_\_\_\_\_ 는 데이터가 보낸 그대로 정확하게 수신자에게 도착한다는 것을 의미한다.

-> b. 메시지 무결성

12. \_\_\_\_\_\_\_ 는 인증과 무결성과 메시지의 부인방지를 제공할 수 있다.

-> b. 전자 서명

13. 전자서명은 \_\_\_\_\_\_\_ 을(를) 제공하지 않는다.

-> b. 개인정보보호

14. \_\_\_\_\_\_\_ 에서 단체의 신분은 시스템 접근의 전체 시간동안 한 번 확인된다.

-> a. 개체 인증

15. \_\_\_\_\_\_\_ 암호에서 모든 사람은 모든 사람의 공개키에 접근할 수 있다.

-> b. 비대칭키

16. 메시지는 암호화된 후에 \_\_\_\_\_\_\_ 라고 불린다.

-> b. 암호문

17. 기밀성을 위해 사용되는 비대칭키 방법에서 어떤 키가 공개적으로 알려지는가?

-> b. 복호화 키만

18. 기밀성을 위해 사용되는 비대칭키 방법에서 수신자는 메시지를 복호화하기 위해 그/그녀 자신의 \_\_\_\_\_\_\_ 를 사용한다.

-> b. 공개키

19. 기밀성을 위한 RSA 알고리즘은 \_\_\_\_\_\_\_ 암호를 사용한다.

-> a. 비대칭키

20. RSA에서 사용자 A가 암호화된 메시지를 사용자 B에게 보내려는 경우, 평문은 \_\_\_\_\_\_\_ 의 공개키를 사용하여 암호화된다.

-> b. 사용자 B

21. 전자서명 기술에서 비대칭키를 사용하여 전체 메시지에 서명할 때, 메시지의 송신자는 메시지에 서명하기 위해 \_\_\_\_\_\_\_ 를 사용한다.

-> b. 그 또는 그녀 자신의 개인키

22. 전자서명 기술에서 비대칭키를 사용하여 전체 메시지에 서명할 때, 메시지의 수신자는 서명을 검증하기 위해 \_\_\_\_\_\_\_ 를 사용한다.

-> c. 송신자의 공개키

23. \_\_\_\_\_\_\_ 는 대칭키 배포의 문제를 해결하는 신뢰된 제3자 기관이다.

-> b. KDC

24. \_\_\_\_\_\_\_ 는 공개키와 키의 주인 사이의 결속을 인증한다.

-> a. CA

모든 답은 '데이터 통신과 네트워킹 5판(Data Communications and Networking Fifth Edition, Behrouz A. Forouzan 저)' 책을 공부하며 작성 하였습니다.
