1. VPN기술은 기관의 개인정보보호를 보장하기 위해 2개의 기술을 동시에 사용한다. \_\_\_\_\_\_\_ 과 \_\_\_\_\_\_\_ .

-> c. IPSec; 터널링

2. IP 보안(IPSec)은 \_\_\_\_\_\_\_ 수준에서 패킷의 보안을 제공하기 위해 IETF(Interner Engineering Task Force)에서 설계한 프로토콜의 집합이다.

-> b. 네트워크

3. IPSec은 2개의 호스트 사이에 \_\_\_\_\_\_\_ 라 불리는 신호처리 프로토콜을 사용하는 논리적인 연결이 필요하다.

-> b. SA

4. IPSec은 두 가지 \_\_\_\_\_\_\_ 모드와 \_\_\_\_\_\_\_ 모드로 동작한다.

-> b. 전송; 터널

5. \_\_\_\_\_\_\_ 모드에서 IPSec 헤더는 IP 헤더와 패킷의 나머지 사이에서 더해진다.

-> a. 전송

6. \_\_\_\_\_\_\_ 모드에서 IPSec 헤더는 원본 IP 헤더의 앞에 배치된다.

-> b. 터널

7. IPSec은 2개의 프로토콜 \_\_\_\_\_\_\_ 와 \_\_\_\_\_\_\_ 을 정의한다.

-> d. Answers & Solutions없음 (a. AH; SSP, b. ESP; SSP, c. AH; EH)

8. \_\_\_\_\_\_\_ 프로토콜은 발신지 호스트를 인증하고 IP 패킷에 운반되는 페이러도의 무결성을 보장하기 위해 설계되었다.

-> a. AH

9. \_\_\_\_\_\_\_ 프로토콜은 메시지 인증과 무결성을 제공하지만 개인정보보호는 제공하지 않는다.

-> a. AH

10. \_\_\_\_\_\_\_ 프로토콜은 메시지 인증과 무결성과 개인정보보호를 제공한다.

-> b. ESP

11. \_\_\_\_\_\_\_ 는 전송층의 보안을 제공하기 위해 설계되었다.

-> c. TLS

12. \_\_\_\_\_\_\_ 는 전자우편의 전송에서 보안의 네 가지 측면을 모두 제공하기 위해 필 짐머만(Phil Zimmermann)이 발명하였다.

-> d. Answers & Solutions없음 (a. AH, b. ESP, c. TLS)

13. 패킷 필터 방화벽은 \_\_\_\_\_\_\_ 또는 \_\_\_\_\_\_\_ 계층에서 동작한다.

-> c. 네트워크; 전송

14. 프록시 방화벽은 \_\_\_\_\_\_\_ 계층에서 동작한다.

-> c. 응용

15. 전송 모드에서 IPSec은 \_\_\_\_\_\_\_ 를 보호한다.

-> b. 전송층으로부터의 페이로드

16. 터널 모드에서 IPSec은 \_\_\_\_\_\_\_ 를 보호한다.

-> a. IP 헤더

17. ESP 프로토콜은 \_\_\_\_\_\_\_ 설계되었다.

-> a. AH 프로토콜 다음에

18. IPSec에서 접근 제어는 \_\_\_\_\_\_\_ 를 사용하여 제공된다.

-> b. 보안 협상 데이터베이스

19. IKE는 \_\_\_\_\_\_\_ 를 제공한다.

-> c. 인바운드 SA와 아웃바운드 SA 모두

20. IKE는 \_\_\_\_\_\_\_ 개의 구성요소로 만들어진다.

-> c. 3

21. SSL은 \_\_\_\_\_\_\_ 개의 프로토콜을 사용한다.

-> d. 4
