**문제:**

다음과 같이 출력하도록 코드를 작성해 주세요.

```cpp
!@#$%^&*(\'"<>?:;
```

**풀이:**

```cpp
print(#"!@#$%^&*(\'"<>?:;"#)

// 또는
// print("!@#$%^&*(\\'\"<>?:;")
```

swift에서는 특수문자를 출력하는 데 여러 방법이 있습니다.

그 중 문자열 앞 뒤로 # 을 사용하면 특수문자를 그대로 출력합니다.

또는 아래 주석처럼 \ 이나 " 처럼 이미 키워드로 사용하고 있는 특수문자들은 앞에 \ 를 하나 붙여주면 특수문자가 문자열 그대로 출력됩니다.
